# Wiegman Ugly Sweater Party — Photo Booth

A one-page web app that turns an iPad into a party photo booth: live camera preview, countdown, holiday frames, single or 4-pack shots, and a share button for texting, emailing or AirDropping each photo. Photos are also kept in an on-device gallery.

Open the GitHub Pages link in Safari on the iPad, tap Share → Add to Home Screen, and launch it from there. The camera only works over https.
